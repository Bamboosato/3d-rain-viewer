| 項目 | 内容 |
| :--- | :--- |
| **システム名称** | リアルタイム雨雲×3D地形ビューア（仮称：3D RainScape / JAXA Rain3D） |

| **レンダリング & UI基盤** | **WebGPU**（次世代3D/コンピュート描画） ＋ **View Transitions API**（ネイティブUI遷移） |

| **想定プラットフォーム** | モダンWebブラウザ（PC、タブレット、スマートフォン） |

## 2. 目的と背景

### 2.1 開発の背景
従来の平面（2D）雨雲レーダーでは、山脈に衝突して生じる上昇気流や谷筋への雨雲の流入といった「地形性降雨」のメカニズムを直感的に把握することが困難でした。
日本の降水特性に深く関わる「地形」と「雨雲」の立体的な相関を、誰でもブラウザ上で自在に俯瞰・分析できる環境が求められています。

### 2.2 システムの目的
JAXA Earth APIのオープンデータ（全球降水GSMaP、全球標高AW3D30）を活用し、ブラウザ上で滑らかに動作する3D雨雲ビジュアライザを提供します。
**WebGPU** による低負荷・高フレームレートな3D描画と、**View Transitions API** による滑らかなUI状態遷移を採用することで、ハイエンドPCからモバイル端末まで極めて快適な基本性能（Core Web Vitals最優秀水準）を実現します。

## 4. システムアーキテクチャ & レンダリングパイプライン

VercelのグローバルCDNから静的アセットを配信し、大容量の衛星データ（COG/STAC）はクライアントからJAXA配信サーバーへ直接HTTP Range Requestを行う**サーバーレス・JAMstack構成**です。

```
[ GitHub Repository ] ── (Push / PR) ──> [ Vercel CI/CD ]
                                                │ (Build: vite build)
                                                ▼
[ エンドユーザー ブラウザ ] <─── (配信) ─── [ Vercel Edge Network ]
       │                                     (HTML, JS, CSS, Assets)
       ├── UI層: View Transitions API (GPUネイティブ変形・フェード遷移)
       │     ▲
       │     └── Tailwind CSS / React Components
       │
       ├── 描画層: MapLibre GL JS (WebGPU レンダリングバックエンド)
       │     ▲  ※未対応ブラウザ環境では WebGL2 へ自動フォールバック
       │     ├── 標高タイル (Terrain RGB) ─── JAXA Earth API (AW3D30 COG)
       │     ├── 降水ラスタレイヤー ───────── JAXA Earth API (GSMaP COG)
       │     └── 雨滴・霧パーティクル ──────── WebGPU Compute Shader
       │
       └── データ通信層: JAXA Earth API for JavaScript (v2.0+)
             └── ブラウザから直接データ取得（APIキー不要、CORS対応済み）
```

### コア技術スタック
* **グラフィックス基盤**: **WebGPU**（高並列コンピュートシェーダー、メモリ帯域最適化、WebGL2フォールバック対応）
* **UIアニメーション基盤**: **View Transitions API**（外部アニメーションライブラリ不要、GPUコンポジター直結のゼロJSオーバーヘッド遷移）
* **ビルドツール**: Vite (React + TypeScript)
* **スタイリング**: Tailwind CSS
* **地図エンジン**: MapLibre GL JS (v4.x以降、WebGPU対応)
* **衛星データ接続SDK**: JAXA Earth API for JavaScript (v2.0+ ESM、型定義 `jaxa.earth.esm.d.ts` 適用)
* **ホスティング & CI/CD**: Vercel (Hobbyプラン、GitHub連携)

## 6. 機能要件

### 6.1 3Dマップ表示機能 (F-Map)
- **F-Map-01: WebGPU駆動 3D地形レンダリング**  
  AW3D30データ由来のTerrain RGBタイルをWebGPUパイプラインで描画し、山岳・平野の起伏を常時60〜120fpsでスムーズに立体描画する（非対応環境はWebGL2にフォールバック）。
- **F-Map-02: 自由なカメラワーク**  
  マウス・タッチによるパン、回転、チルト（ピッチ角 0〜85度）、ズームを低遅延で制御する。
- **F-Map-03: 標高強調（Exaggeration）スライダー**  
  平野部と山間部のメリハリを視覚的に強調するため、高さ倍率を1.0倍〜3.0倍の範囲で動的変更可能とする。
- **F-Map-04: 背景地図（ベースマップ）切替**  
  OpenStreetMap（標準）、起伏陰影マップ、衛星写真（オルソ航空写真）のレイヤー切替をサポートする。
- **F-Map-05: WebGPU雨滴・霧パーティクル演出（拡張機能）**  
  WebGPUコンピュートシェーダーを活用し、降水強度（mm/h）に応じた立体的な雨滴や霧のエフェクトを地形表面にリアルタイム生成する。

### 6.2 降水可視化機能 (F-Rain)
- **F-Rain-01: GSMaP最新観測レイヤー重畳**  
  JAXA Earth APIから直近の全球降水マップを取得し、3D地形表面に半透明ラスタレイヤーとしてプロットする。
- **F-Rain-02: 雨量カラーマップ凡例**  
  降雨強度（mm/h）に応じたカラースケール（0.5mm未満の小雨〜80mm以上の猛烈な雨）を画面上に常時表示する。
- **F-Rain-03: 降水レイヤー透過度調整**  
  地形テクスチャの視認性を保つため、不透明度を0%〜100%の範囲でスライダー調整可能とする。

### 6.3 時系列タイムラプス機能 (F-Time)
- **F-Time-01: 過去24時間シークバー**  
  過去24時間〜最新観測時刻までを1時間単位でシームレスに切り替えられるスライダーを提供する。
- **F-Time-02: 自動アニメーション再生**  
  時系列データを自動でループ再生（再生速度 1x / 2x 切り替え）し、雨雲の推移を動画的に表示する。
- **F-Time-03: 観測時刻（JST）表示**  
  現在表示されているデータの観測日時を視認性の高いバッジ形式でリアルタイム表示する。

### 6.4 ナビゲーション・UIトランジション機能 (F-Nav / F-UI)
- **F-Nav-01: 山岳・注目スポット視点プリセット（View Transitions連動）**  
  代表エリア（富士山周辺、北アルプス・槍ヶ岳、阿蘇山、丹沢山地など）へワンタップで3D斜め視点（ピッチ60度）にフライ移動する。移動時、対象地点名や標高バッジがView Transitions APIによって滑らかに変形・フェード移動する。
- **F-Nav-02: 地点インスペクター（View Transitions連動）**  
  地図クリック時に、該当地点の「地点座標」「標高（m）」「現在推定雨量（mm/h）」をポップアップカードで表示する。カードの出現・移動はView Transitions APIでアニメーション処理する。
- **F-Nav-03: GPS現在地ジャンプ**  
  ブラウザのGeolocation APIと連動し、ワンタップで現在地へカメラを滑らかにフォーカスする。

## 7. 非機能要件 & 基本性能目標

| 分類 | 要件内容 |
| :--- | :--- |
| **グラフィックス性能** | ・WebGPUによるGPUハードウェア直結描画により、3Dシーンのフレームドロップ（Jank）を根絶<br>・フレームレート：PC環境 60〜120fps、スマートフォン環境 60fps安定描画を目標<br>・未対応ブラウザに対するWebGL2自動フォールバック機構を内蔵 |
| **UI応答性（INP）** | ・View Transitions APIの採用により、重いJSアニメーションライブラリ（Framer Motion等）を完全排除し、バンドルサイズを数十KB削減<br>・ユーザー操作（ボタン押下、視点移動、スライダー操作）に対する応答時間（INP）200ms以内（Good判定） |
| **ホスティング環境** | ・Vercel Hobbyプラン（無償枠）で完全稼働<br>・GitHub `main` ブランチへのプッシュで自動ビルド＆本番反映<br>・プルリクエストごとのPreview環境による動作事前検証 |
| **データ通信効率** | ・COG形式のHTTP Range Requestにより、表示領域外の不要データ転送を抑制<br>・Vercel側の月間転送量制限（100GB）に影響を与えないクライアント直アクセス構成 |
| **ライセンス・クレジット** | ・画面内（Infoモーダルまたはフッター）にJAXA Earth API、AW3D30、GSMaPのクレジットおよび利用規約リンクを明記 |

## 9. 開発マイルストーン

### Milestone 1: 環境構築 & WebGPU MVPプロトタイプ
- Vite + React + TypeScript + Tailwind CSSのプロジェクト初期化
- MapLibre GL JS（WebGPUバックエンド有効化）による3D地形（AW3D30）のレンダリング
- JAXA Earth API for JavaScriptを用いたGSMaP単一観測データの重畳テスト
- GitHubリポジトリ作成とVercel初回デプロイ連携

### Milestone 2: View Transitions API & UIコンポーネント実装
- `document.startViewTransition()` を組み込んだUI状態遷移（プリセット切り替え、インスペクター表示）の実装
- 外部アニメーションライブラリを使わない軽量なネイティブトランジションCSS定義
- 過去24時間の時系列スライダーおよび自動ループ再生処理の実装

### Milestone 3: 品質最適化 & 本番公開
- WebGPU非対応環境（古いモバイルブラウザ等）でのWebGL2フォールバック検証
- モバイル・タブレット向けタッチジェスチャーとUIリサイズ対応
- JAXAクレジットモーダル、免責事項の整備
- Vercel本番ドメインへのデプロイとCore Web Vitals計測
