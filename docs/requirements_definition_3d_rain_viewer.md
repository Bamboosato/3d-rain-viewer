| 項目 | 内容 |

## 2. 目的と背景

### 2.1 開発の背景
従来の平面（2D）雨雲レーダーでは、山脈に衝突して生じる上昇気流や谷筋への雨雲の流入といった「地形性降雨」のメカニズムを直感的に把握することが困難でした。
日本の降水特性に深く関わる「3D地形」と「リアルタイム雨雲」の立体的な相関を、誰でもブラウザ上で自在に俯瞰・分析できる環境が求められています。

### 2.2 システムの目的
気象庁の高解像度降水ナウキャスト（リアルタイム性）とJAXA Earth APIのオープンデータ（AW3D30 30m全球標高・GSMaP衛星全球降水）をハイブリッド統合し、ブラウザ上で滑らかに動作する3D雨雲ビジュアライザを提供します。
**WebGPU** による低負荷・高フレームレートな3D描画と、**View Transitions API** による滑らかなUI状態遷移を採用し、PC・スマートフォン双方で優れた操作性とレスポンスを実現します。

| ユーザー層 | 主な利用シーン・ニーズ |

| **登山者・キャンパー** | 目的地の山岳エリア（日本百名山や登録したお気に入りスポット）に雨雲が引っかかっているか、天候悪化の兆候がないかを直感的に把握する。 |
| **教育・地理ファン** | 中学・高校の理科・地理分野で、山岳性降雨や風配図・地形効果を視覚的に学ぶ教材として活用する。 |

## 4. システムアーキテクチャ & レンダリングパイプライン

VercelのグローバルCDNから静的アセットを配信し、大容量の衛星データ（COG/STAC）や気象庁タイルはクライアントから直接取得する**サーバーレス・JAMstack構成**です。

```
[ GitHub Repository ] ── (Push: main) ──> [ Vercel CI/CD ]
                                                │ (Build: vite build)
                                                ▼
[ エンドユーザー ブラウザ ] <─── (配信) ─── [ Vercel Edge Network ]
       │                                     (HTML, JS, CSS, Assets)
       ├── UI層: View Transitions API (GPUネイティブ変形・フェード遷移)
       │     ▲
       │     └── Tailwind CSS / React Components
       │
       ├── 描画層: MapLibre GL JS (WebGPU レンダリングバックエンド)
       │     ▲  ※未対応ブラウザ環境では WebGL2 へ自動フォールバック
       │     ├── 標高タイル (Terrain RGB) ─── JAXA Earth API (AW3D30 DSM v3.2)
       │     ├── リアルタイム雨雲 ───────────── 気象庁 高解像度降水ナウキャスト / 今後の雨
       │     ├── 衛星確定値降水レイヤー ────── JAXA Earth API (GSMaP COG)
       │     └── 3D地形陰影 (Hillshade) ────── WebGPU / WebGL2 シェーダー
       │
       ├── データ通信層:
       │     ├── 気象庁 高解像度降水ナウキャスト（5分更新、実況2h〜予測15h）
       │     ├── JAXA Earth API for JavaScript (v2.0+ ESM、AW3D30 / GSMaP)
       │     └── ローカルストレージ（お気に入り地点・カメラ設定永続化）
       │
       └── PWA / モバイル最適化層:
             ├── Service Worker & Web Manifest（ホーム画面追加・スタンドアロン起動）
             ├── iPhone セーフエリア対応（env(safe-area-inset-*)）
             └── タッチ操作最適化（ダブルタップ拡大抑止、iOSフォームズーム防止）
```

## 6. 機能要件

### 6.1 3Dマップ表示機能 (F-Map)
- **F-Map-01: WebGPU駆動 3D地形レンダリング**  
  AW3D30データ由来のTerrain RGBタイルをWebGPUパイプラインで描画し、山岳・平野の起伏をスムーズに立体描画する（非対応環境はWebGL2に自動フォールバック）。
- **F-Map-02: 自由なカメラワーク**  
  マウス・タッチによるパン、回転、チルト（ピッチ角 0〜85度）、ズームを低遅延で制御する。
- **F-Map-03: 標高強調（Exaggeration）スライダー**  
  平野部と山間部のメリハリを視覚的に強調するため、高さ倍率を1.0倍〜3.0倍（標準1.5倍）の範囲で動的変更可能とする。
- **F-Map-04: 背景地図（ベースマップ）切替**  
  OpenStreetMap（標準）、国土地理院起伏陰影マップ、Esri航空写真のレイヤー切替をサポートする。
- **F-Map-05: 地形陰影（Hillshade）の調和**  
  3D起伏に合わせた陰影レイヤーを動的に重畳し、立体感を強調する。

### 6.2 降水可視化機能 (F-Rain)
- **F-Rain-01: ハイブリッド雨雲データソース**  
  1. **気象庁 高解像度降水ナウキャスト＋今後の雨（リアルタイム）**: 過去2時間の実況（5分間隔）、60分先までのナウキャスト予測、および最大15時間先までの降水短時間予報を動的合成して表示。
  2. **JAXA GSMaP（衛星確定値）**: 地上雨量計補正済みの高精度全球降水データ（過去24時間、1時間間隔）。
- **F-Rain-02: 雨量カラーマップ凡例**  
  降雨強度（mm/h）に応じたカラースケール（小雨〜猛烈な雨）を画面右下に表示（折りたたみ可能）。
- **F-Rain-03: 降水レイヤー透過度調整**  
  地形テクスチャの視認性を保つため、不透明度を0%〜100%（標準70%）の範囲でスライダー調整可能とする。

### 6.3 時系列タイムラプス機能 (F-Time)
- **F-Time-01: 操作しやすいシークバー**  
  過去データから最新観測、将来予測までをスムーズに切り替えられるスライダーを提供する。
- **F-Time-02: 自動アニメーション再生**  
  時系列データを自動でループ再生（再生速度 1x: 1秒/コマ、2x: 0.5秒/コマ 切替）し、雨雲の推移を動画的に表示する。
- **F-Time-03: 直感的なステータス表示**  
  差分時間表示を廃止し、**「過去」「現在」「予測」の固定2文字ラベル**と**現在時刻境界マーカー**を表示。タップで即座に現在時刻へジャンプ可能。

### 6.4 ナビゲーション & スポット選択機能 (F-Nav)
- **F-Nav-01: 3タブ統合ナビゲーション (`PresetNav`)**  
  上部パネルを「🏔️ 百名山」「⭐ お気に入り」「🔍 地名・施設検索」の3タブに分離し、百名山・お気に入りタブから冗長な検索枠を排して一覧性を向上させる。
- **F-Nav-02: 日本百名山（全100座）ナビゲーション**  
  全100座を完全収録し、地域ブロック（9山域）➔ 都道府県 ➔ 山岳名の階層絞り込みに対応。山岳選択時は自動でダイアログを閉じ、山頂インスペクターを表示する。
- **F-Nav-03: ⭐ お気に入り地点登録 & カメラ視点完全再現**  
  地図上の任意地点や検索地点・現在地をお気に入りとしてブラウザ（`localStorage`）に保存。登録時点の**「縮尺（ズーム）・傾き（ピッチ）・方角（ベアリング）」を記憶**し、ワンタップで忠実に再現する。登録地点の名前変更・上書き更新・削除にも対応。
- **F-Nav-04: 🔍 地名・施設キーワード検索（OpenStreetMap連携）**  
  キーワードから OpenStreetMap（Nominatim Search API）および百名山・お気に入りを横断検索し、全国の地名・施設・山小屋・駅・観光地などの候補リストを表示。候補を選択すると最適ズームでその地点へ3Dカメラが移動し、AW3D30標高と降雨強度を地点インスペクターに自動表示する。
- **F-Nav-05: 地図上ズーム連動「★」マーカー**  
  登録されたお気に入り地点を地図上に金色の「★」マーカーとして常時表示する。
  - **広域表示（ズーム9未満）**: 雨雲を邪魔しないコンパクトな「★」アイコンのみ表示。
  - **拡大表示（ズーム9以上）**: 「★ 地点名」ラベル付きバッジに自動切替。
  - **直接選択**: 地図上のマーカータップで該当視点へ即座にカメラ移動し、インスペクターを開く。
- **F-Nav-06: GPS現在地ジャンプ**  
  ユーザーが調整した現在の縮尺・傾き・方角を維持したまま現在地へスムーズ移動し、地点インスペクターを自動表示する。連打による画面拡大防止およびローディング回転アニメーションを搭載。

### 6.5 詳細インスペクター機能 (F-Insp)
- **F-Insp-01: 地点詳細カード**  
  地図クリック時に、該当地点の「座標」「標高（AW3D30）」「降雨強度（mm/h）」「降水判定」をポップアップ表示する。
- **F-Insp-02: ワンタップお気に入り登録 & OSM施設・地名候補サジェスト**  
  インスペクター内から直接お気に入り地点への登録・名前変更・削除が可能。お気に入り登録・更新フォームを開いたタイミングで OpenStreetMap（Overpass API ＋ Nominatim 逆ジオコーディング）へ非同期リクエストを行い、周辺の山頂・山小屋・キャンプ場・登山口・駅・施設名や市区町村・町字の候補チップを距離順に表示してワンタップで入力できる。

### 6.6 モバイル & PWA最適化機能 (F-Mobile)
- **F-Mobile-01: PWA（Progressive Web App）**  
  Web App ManifestおよびService Workerを備え、ホーム画面追加ボタン（Install Prompt）からスタンドアロンアプリとしてインストール可能。
- **F-Mobile-02: iPhone セーフエリア完全対応**  
  ノッチ・Dynamic Island・ホームバーの `env(safe-area-inset-*)` に配慮したレイアウト設計。iOS Safariにおけるアドレスバー隠蔽・画面下部黒帯を解消。
- **F-Mobile-03: タッチ操作保護**  
  ダブルタップによる意図しない画面全体の拡大を防止（`touch-action: manipulation`）、iOSフォームフォーカス時の自動ズームを防止（16px入力フォント）、ドロップダウン展開中の背後地図誤タップを保護するバックドロップを搭載。
