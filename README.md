# 3D RainScape — リアルタイム雨雲 × 3D山岳地形ビューア

**WebGPU (MapLibre GL JS)** と **View Transitions API** を活用し、日本の山岳地形（**JAXA AW3D30**）上にリアルタイム雨雲（**気象庁 高解像度降水ナウキャスト / 降水短時間予報**）および衛星確定値（**JAXA GSMaP**）を立体的に重ね合わせて可視化するモダンWebアプリケーションです。

---

## 主な機能

- **WebGPU駆動 3D地形レンダリング**:
  - JAXA Earth API (`AW3D30 DSM v3.2`) をリアルタイムに Terrain-RGB タイルへ変換し、山岳の起伏と陰影を高フレームレートで立体描画（WebGPU未対応環境はWebGL2へ自動フォールバック）。
- **ハイブリッド雨雲タイムラプス (`TimelineBar`)**:
  - **📡 リアルタイム雨雲（気象庁ナウキャスト + 今後の雨）**: 過去2時間の実況（5分間隔）、60分先までの高解像度降水ナウキャスト予測、および最大15時間先までの降水短時間予報をシームレスに再生・シーク可能。
  - **🛰️ 衛星確定値（JAXA GSMaP 24h）**: 地上雨量計補正済みの高精度全球降水マップ（過去24時間・1時間刻み）を再生。
  - **直感的な「過去」「現在」「予測」ステータス表示**: 相対差分時間表示を廃止し、固定ラベルと現在時刻境界マーカーで直感的な操作・視認性を実現。PC・スマホ共通のシンプルな1行レイアウト。
- **日本百名山（全100座）ナビゲーション (`PresetNav`)**:
  - 日本百名山全100座を完全収録。地域ブロック（7山域）➔ 都道府県 ➔ 山岳名の階層絞り込みや、山名・よみがなのインクリメンタル検索に対応。山岳を選択すると自動で山頂インスペクターが開きます。
- **⭐ お気に入り地点登録 & カメラ視点完全再現**:
  - 地図上の任意地点や現在地をお気に入りとしてブラウザ（`localStorage`）に保存。
  - **OpenStreetMap（Overpass API + Nominatim）による施設名・地名候補サジェスト**: お気に入り登録フォームを開くと、クリック座標周辺の山頂・山小屋・登山口・キャンプ場・駅・施設名および市区町村・地名候補を自動取得し、ワンタップで地点名に入力可能。
  - **登録時のカメラ設定（縮尺・傾き・方角）を完全記憶**: お気に入りを選択すると、登録した視点で正確に再現。
  - **地図上ズーム連動「★」マーカー**: 地図上に金色の「★」マーカーを表示。広域表示（ズーム9未満）ではコンパクトな星アイコン、拡大表示（ズーム9以上）では「★ 地点名」ラベル付きバッジに自動切替。地図上のマーカーをタップするだけで直接視点移動＆インスペクター表示が可能。
- **地点インスペクター (`Inspector`)**:
  - 地図クリックで経緯度・AW3D30標高（m）・降雨強度（mm/h）・降水判定ステータスを即座にポップアップ表示（View Transitions API 連動）。インスペクターからワンタップでお気に入り登録や視点・名前の更新が可能。
- **現在地ジャンプ (`LocateFixed`)**:
  - ユーザーが調整した好みの縮尺（ズーム）・傾き（ピッチ）・方角（ベアリング）を維持したままGPS現在地へスムーズ移動し、地点インスペクターを自動表示。連打による画面拡大防止とローディングアニメーションを搭載。
- **レイヤー＆描画調整 (`LayerMenu`)**:
  - 地形の立体感（高さ強調 1.0x〜3.0x）、雨雲の濃さ（不透明度 0%〜100%）、背景地図（OpenStreetMap / 起伏陰影 / 航空写真）、雨雲データソース切り替えを右上の「設定」パネルに集約。
- **モバイル & PWA最適化**:
  - **PWA（Progressive Web App）対応**: ホーム画面に追加してネイティブアプリ感覚で全画面起動可能。
  - **iPhone セーフエリア完全対応**: ノッチ・Dynamic Island・ホームバーの `env(safe-area-inset-*)` に配慮した余白配置、およびSafari/スタンドアロン起動時の下部黒帯を完全解消。
  - **快適なタッチ操作**: ダブルタップによる意図しない画面全体の拡大を防止（`touch-action: manipulation`）、iOSでのフォーム入力時自動ズームを防止（16px入力フォント）、選択ダイアログ展開中の地図誤タップ防止バックドロップを搭載。

## セットアップ & 起動方法

### 開発サーバー起動
```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173/` を開きます。

### 本番ビルド & プレビュー
```bash
npm run build
npm run preview
```

## データソース・クレジット

- **JAXA Earth API for JavaScript (v2.0.1)**: AW3D30 全球数値地表モデル / GSMaP 衛星全球降水マップ
- **気象庁**: 高解像度降水ナウキャスト / 今後の雨（降水短時間予報）
- **背景地図**: OpenStreetMap contributors / 国土地理院 地理院タイル / Esri World Imagery
- **3D地図描画エンジン**: MapLibre GL JS
