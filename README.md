# 3D RainScape — リアルタイム雨雲 × 3D山岳地形ビューア

🌐 **公開URL**: [https://3d-rain-viewer.bamboosato.com/](https://3d-rain-viewer.bamboosato.com/)

**WebGPU (MapLibre GL JS)** と **View Transitions API** を活用し、日本の山岳地形（**JAXA AW3D30**）上にリアルタイム雨雲（**気象庁 高解像度降水ナウキャスト / 降水短時間予報**）および衛星確定値（**JAXA GSMaP**）を立体的に重ね合わせて可視化するモダンWebアプリケーションです。

---

## 主な機能

- **WebGPU駆動 3D地形レンダリング**:
  - JAXA Earth API (`AW3D30 DSM v3.2`) をリアルタイムに Terrain-RGB タイルへ変換し、山岳の起伏と陰影を高フレームレートで立体描画（WebGPU未対応環境はWebGL2へ自動フォールバック）。
- **ハイブリッド雨雲タイムラプス (`TimelineBar`)**:
  - **📡 リアルタイム雨雲（気象庁ナウキャスト + 今後の雨）**: 過去2時間の実況（5分間隔）、60分先までの高解像度降水ナウキャスト予測、および最大15時間先までの降水短時間予報をシームレスに再生・シーク可能。自動再生は予測の終端（右端）で心地よく自動停止（手動で右端までシークした時と同じ状態）。
  - **🛰️ 衛星確定値（JAXA GSMaP 24h）**: 地上雨量計補正済みの高精度全球降水マップ（過去24時間・1時間刻み）を再生。
  - **直感的な「過去」「現在」「予測」ステータス表示**: 相対差分時間表示を廃止し、固定ラベルと現在時刻境界マーカーで直感的な操作・視認性を実現。PC・スマホ共通のシンプルな1行レイアウト。
- **📈 タイムライン引き出し式 降水量推移グラフ (`RainfallChart` / `pointTimeseriesClient`)**:
  - **プルアップ／プルダウン引き出し（ボトムシート型ドロワー）**: タイムラインバー上端のドラッグハンドルを上へスワイプ／ドラッグ（またはタップ）で引き出し、下へスワイプで格納。展開時は背後の雨量凡例を自然にカバーする最適レイアウト。
  - **現在地図中心座標（`map.getCenter()`）の過去〜未来雨量推移**: 地図移動完了時（300msデバウンス）に中心地点の全フレーム降水量（mm/h）を高速算出。気象庁ナウキャストでは該当単一タイルの該当ピクセルRGBから気象庁カラーガイドに基づき雨量を即時デコード。メモリキャッシュにより余分な通信を徹底抑制。
  - **スライダー時刻との双方向連動＆自動センタリング**: タイムラインスライダーの操作や自動再生に連動し、現在選択中の時刻バーが常に横スクロール領域の中央に来るよう自動センタリング追従。グラフ上のバーをタップ／クリックして該当時刻へダイレクトにジャンプも可能。
  - **中心照準クロスヘア＆インスペクター排他制御**: グラフ展開中は画面中央に控えめな照準リングを表示し、計測対象地点を視覚的に明示。地図タップで地点インスペクターを開いた際はグラフを自動格納し、逆にグラフを引き出した際はインスペクターを自動で閉じる相互排他制御により、モバイル画面の視認性と操作性を両立。
- **地点切替・検索ナビゲーション (`PresetNav`)**:
  - **🏔️ 百名山タブ**: 日本百名山全100座を収録。地域ブロック（9山域）➔ 都道府県 ➔ 山岳名のシンプルな絞り込みで直感的に選択。
  - **⭐ お気に入りタブ**: 登録したお気に入り地点一覧を表示し、ワンタップで登録時のカメラ視点（縮尺・傾き・方角）を再現。並び順切替（初期表示: 現在地からの「近い順」／「登録順」）、重要地点を最上位に固定する「📌 ピン留め機能」、およびワンタップ視点URL共有を完備。
  - **🔍 地名・施設検索タブ**: OpenStreetMap（Nominatim Search API）と連携し、全国の地名・施設名・山小屋・駅名・観光地などのキーワードから候補リストを表示。選択するとその地点へ3Dカメラが移動し、標高と雨量をインスペクターに自動表示。
- **⭐ お気に入り地点登録 & カメラ視点完全再現**:
  - 地図上の任意地点や現在地をお気に入りとしてブラウザ（`localStorage`）に保存。
  - **OpenStreetMap（Overpass API + Nominatim）による施設名・地名候補サジェスト**: お気に入り登録フォームを開くと、クリック座標周辺の山頂・山小屋・登山口・キャンプ場・駅・施設名および市区町村・地名候補を自動取得し、ワンタップで地点名に入力可能。
  - **登録時のカメラ設定（縮尺・傾き・方角）を完全記憶**: お気に入りを選択すると、登録した視点で正確に再現。
  - **地図上ズーム連動「★」マーカー**: 地図上に金色の「★」マーカーを表示。広域表示（ズーム9未満）ではコンパクトな星アイコン、拡大表示（ズーム9以上）では「★ 地点名」ラベル付きバッジに自動切替。地図上のマーカーをタップするだけで直接視点移動＆インスペクター表示が可能。
- **💾 お気に入りの保存・復元・端末間引き継ぎ (`FavoritesSyncDialog` / `favoritesTransfer`)**（サーバー不要）:
  - お気に入りタブの「保存・復元」から、**JSONファイルへの保存／復元**（スマホは共有シート、PCはダウンロード）。
  - **同期URL / QRコード**: お気に入り全件を `deflate-raw` 圧縮して URL フラグメント `#fav=...` に埋め込み（フラグメントはサーバーへ送信されません）。別端末でQRを読み取る・URLを開くと取り込み確認を表示。QRライブラリ（`qrcode-generator`）は表示時のみ動的読み込み。
  - 取り込みは **「追加」（既定。同一地点は更新日時が新しい方を採用）／「置き換え」** を選択可能。取り込み直前の状態を1世代退避し「元に戻す」に対応。
  - 入力検証（件数上限500件・座標範囲・文字数）、`navigator.storage.persist()` による自動削除対策、未バックアップ時の推奨バッジ表示。
- **地点インスペクター (`Inspector`)**:
  - 地図クリックで経緯度・AW3D30標高（m）・降雨強度（mm/h）・降水判定ステータスを即座にポップアップ表示（View Transitions API 連動）。インスペクターからワンタップでお気に入り登録や視点・名前の更新が可能。
- **現在地ジャンプ (`LocateFixed`)**:
  - ユーザーが調整した好みの縮尺（ズーム）・傾き（ピッチ）・方角（ベアリング）を維持したままGPS現在地へスムーズ移動し、地点インスペクターを自動表示。連打による画面拡大防止とローディングアニメーションを搭載。
- **🔗 3D視点＆お気に入り地点ワンタップシェア (`ShareButton` / `Inspector` / `PresetNav` / `urlSync`)**:
  - 現在見ている3Dカメラ視点（緯度 `lat`・経度 `lng`・縮尺 `z`・傾き `p`・方角 `b`）および雨雲データソース（`src`）・観測/予測時刻（`t`）・背景地図（`map`）・標高強調（`ex`）を300msデバウンス（`history.replaceState`）でURLクエリパラメータへ自動同期。
  - ヘッダーの「共有」ボタンに加え、**お気に入り一覧の各アイテム**および**地点インスペクターダイアログ内**にも共有ボタンを搭載。地点共有時はクエリパラメータ `name` に地点名が付与され、共有リンクを開いた相手の画面では3Dカメラ視点とともに**地点インスペクターが自動表示され、共有元の地点名・標高・雨量が即座に表示**されます（そのままワンタップで自分のお気に入りにも追加可能）。
  - モバイルではネイティブシェアシート（`navigator.share`）、PCではクリップボードコピー＋トースト通知で `https://3d-rain-viewer.bamboosato.com/?...` の共有リンクを即座に発行。OGP画像（`og-image.jpg`）にも対応。
- **レイヤー＆描画調整 (`LayerMenu`)**:
  - 地形の立体感（高さ強調 1.0x〜3.0x）、雨雲の濃さ（不透明度 0%〜100%）、背景地図（OpenStreetMap / 起伏陰影 / 航空写真）、雨雲データソース切り替えを右上の「設定」パネルに集約。
- **モバイル & PWA最適化**:
  - **PWA（Progressive Web App）対応**: ホーム画面に追加してネイティブアプリ感覚で全画面起動可能。
  - **iPhone セーフエリア完全対応**: ノッチ・Dynamic Island・ホームバーの `env(safe-area-inset-*)` に配慮した余白配置、およびSafari/スタンドアロン起動時の下部黒帯を完全解消。
  - **快適なタッチ操作**: ダブルタップによる意図しない画面全体の拡大を防止（`touch-action: manipulation`）、iOSでのフォーム入力時自動ズームを防止（16px入力フォント）、選択ダイアログ展開中の地図誤タップ防止バックドロップを搭載。

## セットアップ & 起動方法

### 開発サーバー起動
```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173/` を開きます。

### 本番ビルド & プレビュー
```bash
npm run build
npm run preview
```

## データソース・クレジット

- **JAXA Earth API for JavaScript (v2.0.1)**: AW3D30 全球数値地表モデル / GSMaP 衛星全球降水マップ
- **気象庁**: 高解像度降水ナウキャスト / 今後の雨（降水短時間予報）
- **背景地図**: OpenStreetMap contributors / 国土地理院 地理院タイル / Esri World Imagery
- **3D地図描画エンジン**: MapLibre GL JS
